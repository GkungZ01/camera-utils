# /doc - Workspace Memory & Documentation Maintainer

Triggered when the user types `/doc` or asks to update documentation.

## Workflow
1. **Identify Memory Targets:** Check `notes/.agents/memory/index.md` or `notes/index.md`.
2. **Update Core Profiles/Snippets:** Keep tech stack, server details, or domain glossary up to date.
3. **Token Conservation:** Ensure memory files remain structured, indexed, and concise.
